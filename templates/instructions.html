This application is a web-based 3D Frame Structural Analyzer for defining, analysing and visualising three-dimensional frame structures.

Recommended workflow:

  1. Define Nodes.
  2. Define Members connecting the nodes.
  3. Define Material Properties.
  4. Define Section Properties.
  5. Define Beta Angles if required.
  6. Define Supports.
  7. Apply Nodal and/or Member Loads.
  8. Run ANALYZE.
  9. Review the analysis results and diagrams.
  10. Generate the required report.

The main navigation is: Model → Properties → Supports & Loads → Results → Report.

Use the Previous and Next buttons or the navigation bar to move between sections.

Nodes

  • Each node requires a unique ID.
  • Enter the global X, Y and Z coordinates.
  • Use the same units consistently throughout the model.
  • Define nodes before creating members.

Members

  • Each member requires a unique ID.
  • Specify its Start and End node.
  • Both start and end nodes must exist.
  • A member connects two nodes in the 3D model.

Model View

  • The structure is displayed automatically as inputs are changed.
  • Nodes and members can be visually checked in the 3D view.
  • Use the view controls to rotate, zoom and pan the model.

Material Properties

  • Define the required material properties.
  • Enter the elastic modulus E.
  • Enter the shear modulus G.
  • Assign a material to the required members.
  • Use Assign All when the same material is required for all members.

Section Properties

  • Define the section required for each member.
  • Important section properties are A, Iyy, Izz and J.
  • A section can be assigned to multiple members.
  • Each member should have the required section assigned before analysis.

Beta Angle

  • Beta rotates the local Y-Z axes about the member's local X axis.
  • Beta = 0° means no rotation.
  • Positive beta follows the right-hand rule.
  • Negative beta angles are allowed.
  • Beta is independent of the section property.
  • The same beta property can be reused for multiple members.

3D Section Rendering

  • On the Properties page, use 3D RENDERING to display members using their actual section geometry.
  • The rendered section follows the member's local orientation and beta angle.

Supports define the restrained degrees of freedom at nodes.

Translational DOFs

  • Ux – translation in global X.
  • Uy – translation in global Y.
  • Uz – translation in global Z.

Rotational DOFs

  • Rx – rotation about global X.
  • Ry – rotation about global Y.
  • Rz – rotation about global Z.

Support with Deflection

  • Use the support-deflection option when a restrained DOF has a prescribed displacement or rotation.
  • Only enabled DOFs accept corresponding deflection values.
  • Assign the support to the required nodes.

A stable support system is required for a meaningful structural analysis.

Nodal Loads

  • Nodal forces act in global X, Y or Z.
  • Nodal moments act about global MX, MY or MZ.
  • Assign nodal loads to one or more nodes.

Member Loads

Member loads use the member's local x, y and z directions.

  • Point Load – concentrated load at distance a from the member start.
  • Moment – concentrated moment at distance a.
  • UDL – uniformly distributed load over the member.
  • Partial UDL – distributed load between specified distances a and b.
  • Trapezoidal Load – distributed load varying between two intensities.

Load Assignment

  • Loads can be assigned to selected nodes or members.
  • Use Assign All when the same load is required everywhere.
  • Check the assignment shown on each load card before analysis.

The 3D view displays loads graphically when load visibility is enabled.

Text input fields support simple arithmetic expressions. The expression is evaluated when the input loses focus or when Enter is pressed.

Arithmetic operators

  • Addition: +
  • Subtraction: -
  • Multiplication: *
  • Division: /
  • Parentheses: ( )

Examples

  • 2 + 3 → 5
  • 10 / 2 → 5
  • 2 * (3 + 4) → 14
  • 3.5 + 2.5 → 6

Length Unit Conversion

  • mm → converted to metres.
  • cm → converted to metres.
  • m → metres.
  • in or " → converted to metres.
  • ft or ' → converted to metres.

Examples

  • 300mm → 0.3 m
  • 30cm → 0.3 m
  • 2m → 2 m
  • 12in → 0.3048 m
  • 2ft → 0.6096 m
  • 2'11" → automatically converted to metres.

Tip: You can combine conversion and calculation, for example 300mm + 200mm.

If an expression is invalid, the original input is retained.

Navigation

  • Use left mouse button to rotate the 3D model.
  • Use right mouse button to pa or move the model in the viewing area.
  • Use scroll in mouse or pinch in touchpad to zoom controls to change the viewing distance.

Reset View

  • Click RESET VIEW to automatically refit the model.
  • The view is centred around the model geometry.
  • Use this if the structure moves outside the visible area.

View Options

  • Show Loads – display or hide load symbols.
  • Show Supports – display or hide support symbols.
  • Show Labels – display or hide node/member labels.

The visibility settings affect the graphical representation without changing the structural input data.

Running Analysis

  1. Complete the model.
  2. Assign material and section properties.
  3. Define beta angles where required.
  4. Define supports.
  5. Apply loads.
  6. Click ANALYZE.

The application sends the structural input to the analysis solver and displays the returned results.

Available Results

  • Reactions
  • Displacements
  • Member Forces
  • AFD – Axial Force Diagram
  • SFD – Shear Force Diagram
  • BMD – Bending Moment Diagram
  • TMD – Torsional Moment Diagram
  • Deflection

Analysis results are available only after a successful analysis.

The diagram menu allows independent control of the graphical scale of analysis diagrams.

Available Diagram Scales

  • AFD scale
  • SFD scale
  • BMD scale
  • TMD scale
  • Deflection scale

Scaling Tips

  • Increase a diagram scale when the diagram is too small to see.
  • Decrease the scale when the diagram becomes too large.
  • Each diagram can be scaled independently.
  • Use Reset Diagram Scales to restore the default scales.

Visibility

  • Use Show Loads to control load visibility.
  • Use Show Supports to control support visibility.
  • Use Show Labels to control node and member labels.

Scaling changes only the visual representation of diagrams; it does not modify the calculated structural values.

The Report page allows you to select the information that should appear in the generated structural analysis report.

Report Styles

  • Tabular Report – select individual categories and items for the report.
  • Member-wise Report – generate a report organised member by member.

Tabular Report Contents

  • Nodes
  • Members
  • Supports
  • Loads
  • Reactions
  • Displacements
  • Member Forces
  • SFD
  • BMD
  • Deflection

Member-wise Report

  • Select the required members.
  • Choose the desired member information.
  • Available information includes geometry, loads, end forces, maximum values, SFD, BMD and deflection.

Report Tip

  • Select only the required information for a concise report.
  • Use select-all functionality when the complete model/results are required.
  • Generate the preview after making your selections.

Before Analysis

  • Check that all node IDs are unique.
  • Check that every member references valid start and end nodes.
  • Ensure required material properties are assigned.
  • Ensure required section properties are assigned.
  • Check beta angles for members whose local orientation requires rotation.
  • Check support assignments and restrained DOFs.
  • Check load directions and magnitudes.
  • Check member load positions against the member length.

For a Better 3D View

  • Use RESET VIEW if the model is difficult to locate.
  • Hide loads/supports/labels when they make the model difficult to read.
  • Adjust diagram scales when result diagrams overlap the structure.
  • Use 3D section rendering when checking section orientation.

If Results Are Not Visible

  • Make sure the analysis completed successfully.
  • Check that the Results page is selected.
  • Check diagram visibility settings.
  • Adjust the diagram scale if the diagram is too small or too large.

Important

Always verify the structural model, loading, support conditions, units and assignments before relying on the analysis results.
